# Dependency update

Added `requirements.txt` with the third-party packages used by AiriBot:

- `discord.py>=2.6.0` for the Discord bot and Components V2 UI.
- `Pillow` for generating image cards and dashboards.
- `psutil` for system/process information.
- `python-dotenv` for loading configuration from a `.env` file.
- `rich` for styled terminal output.

Install the dependencies with `pip install -r requirements.txt`.
